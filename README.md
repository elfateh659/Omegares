# Omega Res — نظام متابعة المشروعات والمشتريات

نظام ويب عربي/إنجليزي لمتابعة دورة المشروع بين الإدارات: المكتب الفني ← المشتريات (عروض الأسعار) ← المكتب التنفيذي ← رئيس مجلس الإدارة ← الحسابات ← المشتريات (الشراء) ← المخازن ← مهندس المشروع.

## التشغيل
1. ثبّت **Node.js** (نسخة 18 أو أحدث) من https://nodejs.org — لا يحتاج النظام أي مكتبات إضافية.
2. اضغط مرتين على `start.bat` (أو من الطرفية: `node server.js`).
3. افتح http://localhost:3000
4. الدخول الأول: `admin` / `admin123` — **غيّر كلمة المرور فورًا** من تبويب "حسابي".

للعمل من أجهزة أخرى على نفس الشبكة استخدم العنوان الذي يظهر في نافذة التشغيل (مثل `http://192.168.1.10:3000`)، وقد تحتاج للسماح بالمنفذ 3000 في جدار حماية ويندوز.

## الأدوار
| الإدارة | ما تفعله |
|---|---|
| المكتب الفني | ينشئ المشروع (الاسم، المهندس، البنود والطلبات الفنية) ويرسله، ويتابع الحالة حتى الإغلاق |
| المشتريات | "تم استلام الطلب" ← يضيف أكثر من سعر لكل بند مع صورة العرض ← "تم للمراجعة"، ثم لاحقًا يستلم للشراء ويرفع الفواتير |
| المكتب التنفيذي | يختار سعرًا واحدًا لكل بند ويرسل لرئيس مجلس الإدارة |
| رئيس مجلس الإدارة | موافق / مرفوض (مع ملاحظة) |
| الحسابات | استلام ← جاري التنفيذ ← صرف المبلغ "تم التنفيذ" |
| المخازن | فحص الأصناف ← إدخالها لأرصدة المخزن تحت اسم المشروع ← "إرسال إلى المشروع" |
| مهندسو المشروعات | المهندس المذكور في المشروع يضغط "تأكيد الاستلام" فيُغلق المشروع |
| تكنولوجيا المعلومات / الأدمن | إضافة الموظفين في كل إدارة، تغيير الإدارة، إيقاف الحساب، تعيين كلمة مرور |

الأدمن يستطيع "العرض كـ" أي إدارة لتجربة النظام.

## الفروع (القاهرة والإسكندرية)
- عند إضافة موظف يُختار فرعه: فرع القاهرة، فرع الإسكندرية، أو "كل الفروع" (لمن يتابع الفرعين مثل رئيس مجلس الإدارة أو تكنولوجيا المعلومات).
- كل مشروع وصنف مخزن وطلب صرف يتبع فرعًا، وموظف الفرع يرى بيانات فرعه فقط، ومهندس المشروع يُختار من نفس الفرع.
- مدير النظام ومن لهم "كل الفروع" يختارون الفرع من أعلى الصفحة، ويختارون فرع المشروع أو الصنف أو طلب الصرف عند إنشائه.
- البيانات الموجودة قبل إضافة الفروع اعتُبرت تابعة لفرع القاهرة، ويمكن تغيير فرع أي موظف من صفحة الموظفين.

## المخزن العام وطلبات الصرف
- **أرصدة المخزن ← المخزن العام**: كل الأصناف بأرصدتها، ولكل صنف كود (OR000001…) وباركود Code 128. الصنف الخاص بمشروع يظهر بجواره اسم المشروع.
  - أصناف المشروعات تدخل تلقائيًا عند "إدخال الأصناف للمخزن"، ويُصفَّر رصيدها عند "إرسال إلى المشروع".
  - المخازن تضيف أصنافًا عامة برصيد افتتاحي وتزيد كمياتها.
  - **الأرصدة تظهر لموظفي المخازن (ومدير النظام) فقط.** باقي الموظفين يرون قائمة الأصناف المتاحة بدون أرصدة أو كميات أو أسعار، والخادم نفسه لا يرسل لهم الأرصدة.
  - خانة البحث تعمل مع قارئ الباركود مباشرة. زر "طباعة ملصقات الباركود" (لموظفي المخازن فقط) يفتح صفحة ملصقات A4 للطباعة (اسمح بالنوافذ المنبثقة).
- **طلبات الصرف**: أي موظف يطلب أصنافًا ← تظهر للمخازن للعلم وللمكتب التنفيذي للموافقة ← بعد الموافقة تستلم المخازن وتنفذ فيُخصم الرصيد ← يصل تنبيه لصاحب الطلب والمكتب التنفيذي.

## البيانات والنسخ الاحتياطي
- كل البيانات في `data/db.json`، والمرفقات (عروض الأسعار والفواتير) في `data/uploads/`.
- للنسخ الاحتياطي: انسخ مجلد `data` بالكامل.
- لتغيير المنفذ: `set PORT=8080 && node server.js`
